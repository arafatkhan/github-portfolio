# Arafat Khan — GitHub Portfolio Site

A modern, beautiful portfolio website for **[Arafat Khan](https://github.com/arafatkhan)** — Web Developer & AI Enthusiast based in Dhaka, Bangladesh. This site is built dynamically from Arafat's **real GitHub data** (live projects, deployments, and language stats).

![Preview](https://avatars.githubusercontent.com/u/7759504?v=4)

---

## ✨ Features

- 🎨 **Dark glassmorphism UI** with animated gradient accents & floating elements
- ✨ **Animated particle canvas** background with connecting lines
- ⭐ **Real GitHub analysis** — featured projects pulled from Arafat's repos
- 🌐 **Live Sites section** — 22+ projects highlighted, each linking to its deployed GitHub Pages URL
- 💬 **WhatsApp floating button** — visitors can chat instantly
- 📊 **Skill bars** using real repo language detection
- 📱 **Fully responsive** with hamburger mobile nav
- ⌨️ Smooth scroll, typed rotating roles, counters & scroll progress

## 🗂 Project Structure

```
github-portfolio/
├── index.html   → main page (hero, about, projects, live, skills, contact)
├── style.css    → dark glassmorphism theme & animations
├── script.js    → GitHub data, particle system, filters, WhatsApp, reveal-on-scroll
├── README.md    → this file
└── arafat-image.jpg (profile photo, optional)
```

## 🌐 Live Deployment

Open the site at your GitHub Pages root (`yourusername.github.io`) — or place it at:

```
https://arafatkhan.github.io/github-portfolio/
```

## 🚀 Quick Start

1. Clone or download this repo
2. Open `index.html` in a browser — no build step required
3. *Optional:* replace `8801712345678` in `script.js` with your real WhatsApp number
4. *Optional:* put your own `arafat-image.jpg` in this folder and update the `<img>` src in `index.html`
